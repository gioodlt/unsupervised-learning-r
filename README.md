# Unsupervised Learning in R
This Project demonstrates two unsupervised machine-learning techniques in R:
- Principal Component Analysis (PCA)
- K-means clustering

# Project Overview
The Project uses 'USArrests' and 'NCI60' datasets from the 'ISLR2' package, along with simulated data for clustering.
The analysis examines how PCA can reduce the number of variables while preserving important information. It also demonstrated how K-means clustering groups observations based on similarity.

# Topics covered
- Data standardization
- Principal Component Analysis
- Variance explained
- PCA loadings
- Dimensionality reduction
- K-means clustering
- Data Visualization

# Main Findings
For the 'USArrests' dataset, the first principal components retain approximately 95.66% of the total variance. This means the data can be reduces from four variables to three dimensions while preserving most of the information.
The K-means analysis demonstrates how observations can be separated into groups using different values of K. 
The NCI60 analysis shows how PCA can simplify high-dimensional gene-expression data and make it easier to visualize.

# Requirements
- R
- RStudio
- 'ISLR2' package
